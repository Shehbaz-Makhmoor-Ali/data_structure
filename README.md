A structured collection of **C++ Data Structures & Algorithms** laboratory implementations and theoretical notes completed as part of the **BS Data Science** curriculum at **Air University, Islamabad**. Each lab solves practical domain scenarios (hospital triage, student merit ranking, e-commerce order sorting, flight scheduling, browser history) using custom object-oriented pointer implementations.

## ⚙️ How to Compile and Run

Any lab file can be compiled using a standard C++ compiler such as `g++` (MinGW / GCC):

```bash
# Example: Compile and run Lab 09 Task 1
g++ Lab_09_Heap/Task_1_Student_Merit_Ranking.cpp -o task1
./task1
```
